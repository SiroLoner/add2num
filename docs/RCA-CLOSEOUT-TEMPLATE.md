## Root cause analysis

### 5 Whys

1. Vì sao xảy ra triệu chứng?
2. Vì sao nguyên nhân trực tiếp tồn tại?
3. Vì sao quality gate không phát hiện sớm hơn?
4. Vì sao quy trình hoặc spec cho phép khoảng trống đó?
5. Thay đổi hệ thống nào ngăn lỗi lặp lại?

- [ ] Root cause được phân biệt với symptom.
